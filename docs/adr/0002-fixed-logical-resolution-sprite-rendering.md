# 固定逻辑分辨率 480×270 + 精灵化渲染

2026-11-26,视觉打磨期(批一)动工时定下:Canvas 采用固定逻辑分辨率 480×270(16:9),整数倍缩放 + 信箱自适应窗口;场景渲染从「逐帧 Graphics 矢量重绘」改为「精灵/纹理图集」架构;DOM 覆盖层保持原生分辨率,以 Fusion Pixel 像素字体(尺寸取整倍)对齐像素网格。

原因:16x16 像素素材在任意窗口尺寸下直接拉伸会模糊或采样不均;固定逻辑分辨率 + nearest-neighbor 整数倍缩放是像素完美的标准解。精灵化是使用素材图集的前提(逐帧重绘架构承载不了帧动画与 tileset)。渲染层重构的验收硬标准:核心逻辑零改动、同 seed 换皮前后手感一致。

## Considered Options

- **全窗口响应式**:布局灵活,但像素素材非整数缩放必然模糊/不均;放弃。
- **场景改用 DOM 原生分辨率渲染**:违背 ADR-0001 的分工(渲染归 PixiJS、UI 归 DOM);放弃。
